# 教师周课程表生成系统 (create_kebiao)

专为中小学及高校教师量身定制的周课程表编排与 Excel / 打印导出系统。

## 核心功能特点

1. **基础信息设置**：
   - 教师姓名（自动用于导出的 Excel 命名和表头显示）
   - 学年与学期（支持快捷选择）
   - 学校名称、教研组及底部备注信息

2. **高效周课表编排**：
   - 包含周一至周五（支持一键开启周末）
   - 标准上午 4 节、下午 4 节（支持扩展晚自习/第 9 节）
   - 支持自定义各节次作息时间
   - 智能高亮配色（按学科自动赋予柔和教育色调）

3. **智能记忆与一键排课**：
   - **自动沿用上次学科配置**：排课时默认预选上次填写的学科与教室，免去重复选科
   - **高二全阶段班级快捷选择**：提供高二（1）~ 高二（17）全部 17 个班级一键填入
   - **连点刷子模式**：激活学科后，点击空白格一键快速填充
   - **整日课程复制**：支持将周一课程批量复制到其他任意工作日
   - **多维度批量清空**：支持按所选科目清空、按班级清空或一键重置全周

4. **导出与打印**：
   - 高保真 Excel 导出（.xlsx 格式，带背景色、粗边框、居中合并时段）
   - 样式预览与 A4 横版打印优化（可直接存为 PDF）
   - 本地自动保存（localStorage 持久化，刷新防丢）及 JSON 导入导出备份

## 本地开发与运行

```bash
# 1. 安装依赖
npm install --legacy-peer-deps

# 2. 启动本地开发服务
npm run dev

# 访问地址：http://localhost:3000
```

## Docker 容器化部署

本项目已针对生产环境配置了生产级多阶段 `Dockerfile`，并内置了针对网络波动和 peer 依赖冲突的防御策略。

### 部署规范与依赖锁文件说明：
- 构建采用多阶段方案（Builder + Runner），依赖按 `package-lock.json` 以 `npm ci --legacy-peer-deps` 精确安装。
- 若删除或修改过依赖，必须先执行以下命令重新生成锁文件（必须带 `--legacy-peer-deps`），再运行部署脚本：
  ```bash
  npm install --legacy-peer-deps --package-lock-only
  ```

### 部署脚本参数配置：
- **镜像名称**：`create_kebiao:latest`
- **容器名称**：`create_kebiao`
- **宿主机对外端口**：`7886`
- **容器内部端口**：`3000`
- **数据持久化目录**：
  - Windows 本地：`D:\docker\create_kebiao\data`
  - Linux 远程：`/bak/docker/create_kebiao/data`

### 1. Windows 本地一键部署：
直接双击运行根目录下的 `redeploy.bat`：
- 自动校验 Docker Desktop 运行状态与锁文件；
- 执行多阶段缓存构建与自动网络重试；
- 清理旧容器并启动新容器，挂载数据卷；
- 自动执行 HTTP 200 健康检查并显示访问 URL：`http://localhost:7886`。

### 2. Linux 远程服务器一键部署：
直接双击运行根目录下的 `upload2remote.bat`：
- 本地构建镜像后打包为 `d:\temp\tar\create_kebiao.tar`；
- 通过 SCP 自动上传至服务器 `172.29.173.42`（用户 `gpzx`）；
- 远程加载镜像并启动容器至指定网段（端口 `7886`）。
